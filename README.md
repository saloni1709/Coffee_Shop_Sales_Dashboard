# ☕ Coffee Shop Sales Analysis using Excel

## 📊 Project Overview

This project focuses on analyzing **coffee shop sales data using Microsoft Excel** to gain meaningful insights into sales performance, customer behavior, product demand, and time-based sales trends.

An **interactive Excel dashboard** has been created using **Pivot Tables, Pivot Charts, Slicers, and KPIs** to support data-driven business decision-making.

---

## 🎯 Objectives

* Analyze total sales and revenue
* Understand customer footfall patterns
* Identify top-selling products and categories
* Analyze sales based on:

  * Day
  * Hour
  * Product size
  * Store location
* Identify sales and order trends
* Create an interactive dashboard for business insights

---

## 📈 Key Performance Indicators (KPIs)

The dashboard tracks the following key metrics:

* 💰 **Total Sales (Revenue)**
* 👥 **Total Footfall**
* 💵 **Average Bill per Person**
* 🧾 **Average Orders per Person**

---

## 📊 Dashboard Insights

The interactive Excel dashboard provides insights into:

* ⏰ Quantity of orders based on different hours
* ☕ Category-wise sales distribution
* 📦 Size-wise order distribution
* 🏪 Footfall and sales by store location
* 🥇 Top products based on sales
* 📅 Weekday-wise order trends
* 🎛️ Interactive slicers for day-wise filtering
