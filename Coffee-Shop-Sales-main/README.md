# Coffee Shop Sales Analysis using Excel

📊 Project Overview
* This project focuses on analyzing coffee shop sales data using Microsoft Excel to gain insights into sales performance, customer behavior, product demand, and time-based trends.
An interactive Excel dashboard has been created using Pivot Tables, Pivot Charts, Slicers to support data-driven decision-making.

🎯 Objectives
- Analyze total sales & revenue
- Understand customer footfall patterns
- Identify top-selling products & categories
- Analyze sales by day, hour, size, and location
- Create a dynamic dashboard for business insights

📈 Key Metrics (KPIs)
* Total Sales (Revenue)
* Total Footfall
* Average Bill per Person
* Average Orders per Person

📊 Dashboard Insights
The Excel dashboard provides:
- ⏰ Quantity ordered based on hours
- ☕ Category-wise sales distribution
- 📦 Size-wise order distribution
- 🏪 Footfall & sales by store location
- 🥇 Top products based on sales
- 📅 Weekday-wise order trends
- 🎛 Interactive slicers (Day-wise filtering)
